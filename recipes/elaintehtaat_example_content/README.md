# Eläintehtaat example content

Default content for local development. Applying the recipe creates:

- the Canvas **front page** (`/front`, Finnish default with an English
  translation): a lede text, the key numbers block and the recent media, albums
  and projects views, rendered through the `landing_page` page variant,
- the Canvas **About us / Tietoa meistä** page (`/about-us`, `/tietoa-meista`),
  two text components with mock copy,
- **Species**, **Use** and **Licence** taxonomy terms in English and Finnish,
- the **main** menu link to the About page and the grouped **footer** menu,
- the **Eläintehtaat 2024** project with two albums, **Meat pig farm,
  Jokioinen** (three images) and **Fox farm, Kaustinen** (one image), and the
  image media and files they use. Project, albums and media have English
  defaults and Finnish translations.

Content that already exists (matched by UUID) is skipped, so the recipe is safe
to apply repeatedly.

## Apply

```sh
docker compose exec app drush recipe:apply /var/www/html/recipes/elaintehtaat_example_content
docker compose exec app drush pathauto:aliases-generate all canonical_entities:node -y
```

## Front page

`system.site: page.front` is `/front`, the alias of the front page in both
languages. The import does not keep entity IDs and the importer orders
entities by their dependencies, not by file, so `/page/1` would point at
whichever Canvas page happens to be imported first. Keep the alias when
re-exporting the front page.

## Update the content

Edit the entities on a local site, then re-export them into `content/`:

```sh
docker compose exec app vendor/bin/dr content:export canvas_page --dir=/var/www/html/recipes/elaintehtaat_example_content/content
docker compose exec app vendor/bin/dr content:export taxonomy_term --dir=/var/www/html/recipes/elaintehtaat_example_content/content
docker compose exec app vendor/bin/dr content:export menu_link_content --dir=/var/www/html/recipes/elaintehtaat_example_content/content
docker compose exec app vendor/bin/dr content:export node <nid> --dir=/var/www/html/recipes/elaintehtaat_example_content/content
```

Export an album with `--with-dependencies` to pull in its project, terms, media
and files in one go. Image files are copied next to their `file/*.yml` entries:

```sh
docker compose exec app vendor/bin/dr content:export node <album nid> --with-dependencies --dir=/var/www/html/recipes/elaintehtaat_example_content/content
```

Check the export for a `user/` directory and delete it if one appears: the
admin user already exists on every site and must not be imported.

Canvas pages have no Pathauto pattern, so their aliases are imported as
exported. Album and project aliases are generated by Pathauto from their titles
on import (English) and by the alias generation command above (Finnish), so
they need no special handling.
